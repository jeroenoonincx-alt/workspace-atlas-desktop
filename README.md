# Workspace Atlas for Desktop Start

Tauri 2 Windows-prototype voor Workspace Atlas for Desktop Start.

De huidige Desktop Start-interface is ingebed als lokale frontend. De app gebruikt een native Tauri/Rust-bridge voor:

- lokale `.exe`-bestanden kiezen;
- lokale Windows-programma's starten;
- geregistreerde app-protocollen openen;
- web-URL's als fallback openen.

De tijdelijke VBS/PowerShell/localhost-helper maakt geen deel uit van deze build.
