# Workspace Atlas for Desktop Start

Tauri 2 Windows-app voor **Workspace Atlas for Desktop Start**.

## Actieve testkandidaat

**0.8.3 TEST**

Deze kandidaat gebruikt de goedgekeurde 0.8.3 UX-richting en bevat onder meer:

- gescheiden Werk/Privé-omgevingen;
- lokale opslag van tegels, URL-inbox, activiteiten, taken en notities;
- websites, app-protocollen en lokaal gekozen Windows-`.exe`-bestanden starten;
- expliciete URL-inbox-acties voor openen, verplaatsen, archiveren en verwijderen;
- native Windows-bestandskeuze voor programma's;
- native opslagdialoog voor JSON-back-ups;
- eigen Workspace Atlas-appicoon;
- automatische Windows-build en runtime-rooktest via GitHub Actions.

De tijdelijke PowerShell/VBS/localhost-helper maakt geen deel uit van deze Tauri-build.
